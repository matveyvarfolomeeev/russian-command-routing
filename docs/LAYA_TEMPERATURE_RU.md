# Подбор температуры Laya

Historical experiment record. Paths under `artifacts/` refer to local files; published predictions and ledgers are in [public evidence](../results/README.md).

8 октября 2026 года для Laya FP32 шага 568 подобрана температура **2,4938812077079957**. Веса не обучались заново. Основной retriever — исходная E5; двадцать кандидатов и порядок приложения сохраняются.

## Откуда взялось 0,1

В [конфигурации английской Laya](https://huggingface.co/convaiinnovations/laya/blob/main/rl_agent_config.json) есть `choice:11+ = 0.1005828`. Это настройка конкретного checkpoint. [Multilingual Laya](https://huggingface.co/convaiinnovations/laya-multilingual#limits), которую мы дообучали, поставляется с T = 1 и предлагает подбирать температуру на своих отложенных данных. Перенос английского значения на новые веса не подтверждает калибровку.

Мы проверили в том числе 0,1. При одинаковых logits меньшая температура заостряет распределение, большая — сглаживает. Для положительного T порядок logits сохраняется. Runtime сортирует по исходным logits, чтобы округление слишком малых вероятностей не меняло порядок карточек.

## Протокол

Использованы сохранённые вероятности полного пути исходная E5 → Laya из [парного опыта](E5_LAYA_PIPELINE_RU.md). Все вероятности положительны, без underflow; `log(p)` восстанавливает logits с точностью исходного FP32 softmax до общей константы. Отдельная проверка настоящего worker сопоставляет новые вероятности с этим преобразованием.

- Подбор: independent validation, 50 clean + 50 ASR, 10 групп. Все правильные объекты присутствуют в top-20.
- Отдельная оценка: independent test, 150 clean + 150 ASR, 30 других групп. Пересечений групп и ID нет; эти результаты уже известны, поэтому это не новый слепой тест.
- Старый сложный STT: 100 строк, только описательная оценка; в подборе T не участвует.
- Критерий: средняя conditional multinomial NLL на validation. Число примеров каждой группы одинаково; clean и ASR исходной команды имеют одинаковый вес.
- Диапазон T: 0,05–20, задан до подбора. Минимум найден 80 шагами бисекции по обратной температуре, вдали от границы.
- NLL и multiclass Brier считаются только при наличии цели среди вариантов. ECE и top-label Brier учитывают все запросы, включая промахи retrieval.

## Результат

| Набор и показатель | T = 0,1 | T = 1 | Выбранная T ≈ 2,49 |
| --- | ---: | ---: | ---: |
| Validation100: conditional NLL | 7,0461 | 0,7077 | 0,3721 |
| Test300: conditional NLL, 299 доступных целей | 3,9127 | 0,4044 | 0,2410 |
| Test300: средняя уверенность | 99,95% | 98,92% | 93,35% |
| Test300: ECE, 10 равных интервалов | 5,61% | 4,59% | 3,11% |
| Старый STT100: conditional NLL, 91 доступная цель | 2,5335 | 0,3914 | 0,4586 |
| Старый STT100: ECE | 17,22% | 11,19% | 7,33% |

Top-1 не меняется: validation 92/100, test 283/300, старый STT 80/100. На test multiclass Brier немного ухудшился: 0,09357 → 0,09575; top-label Brier — 0,04894 → 0,05222. На старом STT conditional NLL ухудшилась, хотя end-to-end ECE и top-label Brier стали лучше. Подбор по NLL не гарантирует улучшение каждой метрики и каждого распределения запросов. Десять групп калибровки — ограниченная выборка; устойчивость на новых компьютерах и человеческой речи ещё не измерена.

Для приложения сохранена T ≈ 2,49, выбранная по заявленному validation-критерию. T = 0,1 повышает уверенность без исправления ошибок и сильно ухудшает NLL. Порог уточнения или автоматического запуска по этим данным не выбирался.

## Что подключено

Worker применяет найденную T только к **Laya FP32 с 20 кандидатами**. При меньшем каталоге применяется T = 1: отдельная калибровка для другого числа вариантов не проверялась. Для RuModernBERT остаётся T = 1, оценки E5 остаются cosine similarity.

Конфигурация закрепляет SHA-256 файла калибровки; в нём указаны SHA выбранных весов Laya, тип `choice`, число кандидатов и исходный retriever. При несовпадении worker сообщает ошибку. Исходные checkpoint-файлы и результаты старых опытов не менялись.

Первичные файлы: protocol.json (`artifacts/benchmarks/laya-temperature-v1/protocol.json`), temperature.json (`artifacts/benchmarks/laya-temperature-v1/temperature.json`), отдельные predictions для validation100, test300 и STT100. Повторяемый подбор: `scripts/calibrate_laya_temperature.py`; проверка живого подключения: `scripts/verify_final_model_runtime.py`.

Независимый audit.json (`artifacts/benchmarks/laya-temperature-v1/audit.json`) проверил500 прогнозов и10000 вероятностей через Torch, точный NLL трёх наборов и отсутствие пересечения групп. Autograd-градиент по log(T) в найденном минимуме равен4,3×10⁻¹⁷; соседние T и исходные0,1/1 дают больший validation NLL. Максимальное отличие вероятностей от отдельного Torch softmax —4,4×10⁻¹⁶. Скрипт `scripts/audit_laya_temperature.py` не меняет веса или найденную T.
