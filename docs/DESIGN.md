# Дизайн оболочки

Редизайн по принципам `visual-redesign`: изменения ограничены QML. Python API,
идентификаторы элементов, навигация и обработчики действий сохранены.

| Слой | До | После |
| --- | --- | --- |
| Токены | Синие оттенки распределены по файлам | `Theme.qml`: тёплый графит, светлая нейтральная тема, один зелёный акцент |
| Типографика | Однообразный вес, крупная служебная шапка | Segoe UI Variable, заголовки 25 px, строки 14/12 px, подписи 10/11 px |
| Отступы | Разные поля и плотность контролов | Шаг 4–8 px, поля окна 24 px, единые строки 66 px и контролы 40–42 px |
| Цвет | Синие выделения, чёрные Basic-dropdown и checkbox | Общие состояния выбора, наведения, фокуса и ошибок в обеих темах |
| Компоненты | Смешанные стандартные и собственные контролы | Общие `AppButton`, `Field`, `AppCombo`, `AppCheck`, подсказки `KeyCap` |
| Глубина | Избыточная служебная шапка и яркие карточки | Спокойные плоскости, тонкие границы, поиск занимает главное место |
| Движение | Нет общей системы | Стабильная геометрия без декоративных перемещений; мгновенный понятный hover/focus |

Область риска: редактор и настройки смешивают представление с действиями. Их
обработчики сохранены, изменены размеры, раскладка и контролы. Настройки имеют
прокручиваемое содержимое и постоянную кнопку сохранения. Редактор помещается
в окно и прокручивает длинное содержимое. Длинные строки сокращаются в списках,
а описания и путь переносятся в редакторе. Размеры указаны в логических пикселях
Qt, без ручного масштабирования DPI.

Проверка: существующие UI-тесты, пять превью `scripts/capture_demo.py`, ручная
проверка тёмной/светлой темы и минимального окна 720×560.
