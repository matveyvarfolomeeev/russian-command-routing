# Проверка инженерной версии

Проверено 2 октября 2026 года на Windows 11 x64, Python 3.12.3 и PySide6 6.11.2.

| Проверка | Результат |
| --- | --- |
| pytest | 82 теста прошли; Ruff и git diff --check без ошибок |
| Каталог Windows | Три источника; 222 доступных объекта; Telegram и 7-Zip File Manager по одной записи; без ошибок источников |
| SQLite | Schema 3: проверены миграции, сохранение ID/пользовательских полей, сбои источников, возраст кеша, кириллица и повторное открытие базы |
| Дедупликация | AppID и абсолютный EXE объединяются с однозначным ярлыком; разные аргументы и явно заданные рабочие каталоги сохраняются |
| Кеш | Каталог доступен до фонового обновления; свежая база не пересканируется при повторном старте. Проверка устаревания — при старте и каждый час, порог 24 часа |
| QML | Ввод, Enter, редактор, темы, dropdown, минимальное окно 720×560 и длинные названия; предупреждений QML в проверенных сценариях нет |
| Открытие Windows | В первой инженерной версии наблюдались окна программы, приложения по AppID, папки и ассоциированного файла; модуль запуска не менялся, его тесты проходят |
| Горячая клавиша | Ctrl+Shift+Space проверена через SendInput при запущенном GlazeWM: показ с фокусом, скрытие активного окна, восстановление свёрнутого. Проверены отказ регистрации и восстановление предыдущего сочетания |
| Микрофон | Локально получен WAV: 48 кГц, один канал, 28 800 кадров; аудио не сохранено |
| ASR API | Живой запрос Whisper Large V3 Turbo: синтетическая фраза «Открой блокнот» → «Открой блокнот.». Проверены ошибки, таймаут и отмена устаревшего результата. User-Agent приложения устраняет блокировку стандартного Python-клиента |
| Ключ | Сохранён в пользовательской базе с DPAPI; открытого ключа в БД и Git нет. Проверен приоритет переменной окружения |
| Фильтр | Медиана около 0,6 мс на искусственно расширенном каталоге из 500 объектов; это время функции, не всей UI-операции |
| Превью | Просмотрены новый поиск, каталог, редактор, настройки и светлая тема на вымышленных данных; отдельно — рабочее окно с настоящим каталогом |
| Windows-сборка | Окно примерно за 1,5 с; первый полный каталог за 4,6 с. Запуск из кеша примерно за 1,5 с без скана; повторный запуск и выход с кодом 0 |

Локальные машинные отчёты и снимки находятся в artifacts и не коммитятся. Для повторения используйте команды в README.md и scripts/windows_smoke.py. Последний запуск сохраняет отдельный замер времени до окна и проверяет сохранение даты сканирования при запуске из кеша; это время всего процесса, а не только чтения SQLite.

У старого запущенного процесса отсутствовала регистрация горячей клавиши, но он отвечал на IPC и не зависал. Прямой конфликт с GlazeWM не доказан: старое сочетание работает в изолированном тесте. Старый код не записывал причину стартового отказа. Новый показывает статус, пишет Windows-код ошибки и выполняет одну повторную попытку регистрации.

Сборка проверена отдельно от исходников на этом ПК; отдельная чистая установка Windows 10/11 пока не проверялась. Семантическая точность decision models не измерялась: модели ещё не подключены. Синтетический ASR-тест проверяет интеграцию, а не точность на реальном голосе пользователя.
