# Проверка инженерной версии

Проверено 2 октября 2026 года на Windows 11 x64, Python 3.12.3 и PySide6 6.11.2.

| Проверка | Результат |
| --- | --- |
| pytest | 60 тестов прошли |
| Каталог Windows | Три источника; 236 доступных объектов после объединения; без ошибок источников |
| SQLite | Проверены ID, пользовательские изменения, сбои источников, повторное открытие базы и кириллица |
| QML | Проверены ввод с клавиатуры, Enter, редактор описания и смена темы; предупреждений QML в сценариях нет |
| Открытие Windows | Реально наблюдались окна программы, приложения по AppID, папки и ассоциированного файла; команда ярлыка отправлена, документ виден |
| Горячая клавиша | Проверены регистрация, нативное сообщение Windows, конфликт и снятие регистрации |
| Микрофон | Локально получен WAV: 48 кГц, один канал, 28 800 кадров; аудио не сохранено |
| ASR API | Проверены формат запроса, модель/язык, пустые ответы, ошибки, таймаут и отмена устаревшего результата |
| Ключ | Проверены DPAPI и приоритет переменной окружения |
| Фильтр | Медиана около 0,6 мс на искусственно расширенном каталоге из 500 объектов; это время функции, не всей UI-операции |
| Превью | Просмотрены поиск, каталог, редактор, настройки и светлая тема на вымышленных данных |
| Windows-сборка | Проверены окно, сбор реального каталога, повторный запуск и выход с кодом 0 |

Локальные машинные отчёты и снимки находятся в artifacts и не коммитятся. Для повторения используйте команды в README.md и scripts/windows_smoke.py.

Живой ответ Groq не проверен: API-ключа не было. Сборка проверена отдельно от исходников на этом ПК; отдельная чистая установка Windows 10/11 пока не проверялась. Семантическая точность decision models не измерялась: модели ещё не подключены.
