# Changelog

## 0.1.0 — 2026-10-14

First public research snapshot.

- Research-first README, architecture diagrams and English/Russian resume wording.
- Authored benchmark/training datasets and frozen 22,656-example choice inputs.
- Eight completed fine-tuning/continuation run records, ledgers and checkpoint hashes.
- 4,400 predictions across 11 new-catalog conditions and Laya calibration evidence.
- Standard-library evidence verifier and a portable E5 training-bundle preparer.
- Explicit public-only overlap audit; frozen source bytes preserved in Git.
- Linux evidence checks and Windows source tests in GitHub Actions.
- Existing Windows demonstration application and historical experiment reports.

Model weights, raw audio and personal catalogs are excluded. This release verifies and publishes recorded experiments; it does not claim a new training run or a new blind test.
