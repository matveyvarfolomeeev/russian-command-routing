# launcher-stt-train-v1

Обучающий набор с **искусственными текстовыми ошибками STT**: 16 992 строки,
восемь вымышленных каталогов по 177 объектов, 1 416 целевых объектов. Каждый
ответ — один `open(object_id)`. Запросы сохраняют признаки единственной цели.

Создан из [launcher-train-v1](../launcher-train-v1/README.md): три искажённые
версии каждой из 5 664 строк. До искажения восстановлены 440 исходных клавиатурных
опечаток, чтобы не смешивать их со STT. Сохранены 708 исходных шаблонов и
117 семейств; 16 992 строки не являются независимыми языковыми сценариями.

Это текстовая имитация возможных ошибок. Аудио и API для её генерации не
использовались; частоты операторов заданы генератором, а не измерены у провайдера.
Настоящие ответы API на шумную TTS-речь находятся отдельно в
[launcher-asr-v1](../../benchmarks/launcher-asr-v1/README.md) и остаются в оценке.

## Искажения

Первая версия меняет произношение имени или слова. Вторая меняет запись:
границы слов, алфавит, числа или сокращения. Третья сочетает одно такое изменение
с речевой вставкой, повтором, пропуском команды либо оформлением расшифровки.
11 328 строк содержат один оператор, 5 664 — два.

| Оператор | Число применений | Что меняется |
| --- | ---: | --- |
| phonetic_name | 6 176 | Одна фонетически близкая буква в имени: `Nenaron → Nenoron` |
| phonetic_word | 3 696 | Одна гласная в длинном слове; определяющие имена и уточнения защищены |
| command_mishearing | 1 456 | Форма команды: `Открой → Открою`, `Запусти → Запустить` |
| word_split | 1 656 | `рабочая → раб очая` |
| word_merge | 1 656 | `профилем Firerena → профилемFirerena` |
| script_transcription | 1 656 | Запись имени в другом алфавите: `Бамеван → Bamevan` |
| spoken_number | 160 | `64 → шестьдесят четыре`, `2026 → две тысячи двадцать шесть` |
| spoken_acronym | 536 | `PDF → пи ди эф`, `XLSX → икс эл эс икс` |
| filler | 1 968 | `ну`, `эм`, `так` и другие речевые вставки |
| word_repeat | 1 998 | Повтор слова, иногда уже искажённого |
| command_dropout | 1 230 | Исчезает вводная команда; название/назначение и уточнение остаются |
| punctuation_and_case | 468 | Строчные буквы и пропуск знаков препинания в составном примере |

Сумма применений больше числа строк: составные примеры содержат два оператора.
Числа и форматы заменяются эквивалентной записью: 32 не превращается в 64,
PDF не превращается в DOCX. Фонетические ошибки имён проверяются против других
брендов каталога: отсеяны 510 неоднозначных кандидатов. Ещё 1 115 кандидатов
отсеяны из-за совпадения с чистой фразой или другим искажением. Все 16 992 запроса
различны после нормализации внутри своего каталога; глобально их 15 999.

Примеры из фактических строк:

| Исходная фраза | Искусственная расшифровка | Цель |
| --- | --- | --- |
| Открой приложение Nenaron | Открой приложение Nenoron | Ненарон |
| Открой мессенджер с личным профилем Firerena | Открой мессенджер с личным профилемFirerena | Firerena — личный профиль |
| Запусти Latovika | Запусти Latoveka Latoveka | Latovika |

## Формат и происхождение

- `catalogs.jsonl` — восемь каталогов, идентичных исходному train. У объектов
  только `object_id`, `name`, `kind`, `description`, `aliases`.
- `train.jsonl` — общий формат обучающих строк; `input_type=simulated_asr_text`,
  `source=simulated_stt_text`, `expected_action=open`.
- `operators.json` — фиксированные параметры, фонетические пары, числа,
  сокращения и seed.
- `manifest.json` — SHA-256, статистика, исходный train и защита наборов оценки.

В `augmentation` каждой строки сохранены `parent_id`, чистая `original_query`,
SHA-256 исходного query, факт восстановления клавиатурной опечатки, номер версии
и операции. Каждая операция содержит тип, границы заменяемого фрагмента,
исходный фрагмент и результат. Позиции относятся к тексту перед данной операцией;
последовательное применение точно восстанавливает query. `group_id`, `seed_id`,
каталог и эталонный ID наследуются из исходной строки.

**Вход модели — только искажённый query и полный каталог.** Чистая фраза,
операции, expected_object_id, rationale, parent_id и теги остаются разметкой.
При экспорте правильный ID передаётся только как label, все 177 вариантов
переставляются независимо для каждой строки.

## Отделение от оценки

Зафиксированы шесть наборов: базовый, сложный и ASR-профиль на вымышленном и
реальном каталогах. Проверены отсутствие общих целевых ID, имён целей и
совпадающих нормализованных запросов; файлы оценки защищены хешами. В том числе
отложенные целевые объекты отсутствуют среди отрицательных вариантов train.
Расшифровки ASR-оценки не использовались для создания операторов или обучения.

Набор — **train only**. Не делить случайно строки на train/validation/test:
искажённые версии связаны с исходной фразой и другими подстановками того же
семейства. Базовую, сложную и голосовую точность считать отдельно на сохранённых
наборах оценки. Исходный train и этот профиль можно использовать совместно;
состав смеси должен быть зафиксирован в журнале обучения.

Разметка наследует авторскую проверку исходных шаблонов; правила и защитные
проверки выполнены автором. Независимой человеческой проверки каждой строки нет.
Случаи с полностью потерянным названием/назначением, произвольными галлюцинациями,
уточнениями и отказами в эту обучающую версию не включены.

## Команды

Запуск из корня проекта, без сети и дополнительных зависимостей:

```powershell
.\.venv\Scripts\python.exe -I -X utf8 scripts\stt_training_dataset.py build
.\.venv\Scripts\python.exe -I -X utf8 scripts\stt_training_dataset.py validate
.\.venv\Scripts\python.exe -I -X utf8 scripts\stt_training_dataset.py export
```

Валидация проверяет SHA-256, неизменность исходного train, все метки и операции
повторной генерацией, статистику и отделение от доступных наборов оценки.
Отсутствующие частные наборы явно отмечаются; публичные профили обязательны.

Готовый экспорт: `artifacts/training/launcher-stt-train-v1/kev.train.jsonl`,
16 992 записи `state + choice + label`, около 740 MiB. Его manifest хранит хеш,
размер и результат проверки токенизации. Полный каталог не обрезается.
Проверка тем же закреплённым Qwen3.5-4B-Base токенизатором, что у исходного train,
сохранена в `kev.train.tokenization.json`; для Kev используется `--max_state 16384`.
Полная строка занимает 10 887–11 171 токен; все 16 992 строки помещаются с этим
флагом. Стандартный обучающий контекст не вмещает ни одной строки с 177 вариантами.
Это проверка входного формата и длины, обучение и проверка GPU ещё не проводились.
