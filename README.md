# Jev Launcher

Экспериментальный лаунчер для Windows: открытие приложений, папок и файлов по свободному русскому запросу, в том числе полученному из речи.

Сначала создаём инженерную оболочку с каталогом, описаниями, интерфейсом и открытием объектов. Затем сравниваем decision models и классические ML-методы на одинаковых запросах. Название рабочее; проект не привязан к конкретной модели Jev.

## Текущее состояние

Подготовлены план инженерного MVP и локальный Git-репозиторий. Код приложения, сборка и ML-эксперименты пока отсутствуют.

Основной документ: [план инженерного MVP](MVP_PLAN.md). В нём описаны стек, источники каталога Windows, способы открытия, дизайн, готовая ASR-интеграция и критерии готовности.

Следующий этап — запускаемое окно на Python/PySide6/QML с вымышленным каталогом, после него — сбор реальных объектов Windows и сохранение в SQLite.

## Принципы

- В инженерном MVP пользователь выбирает объект; поиск работает по названию, альтернативным названиям и описанию.
- В последующих экспериментах decision model получает полный доступный каталог.
- Исполняющая часть открывает сохранённый объект по ID.
- Для речи используем готовую стороннюю ASR-модель.
- Личные пути, API-ключи, аудио, локальные модели и результаты запусков не храним в Git.

Проект пока содержит только документацию, поэтому команды установки и запуска появятся вместе с первым работающим приложением.
